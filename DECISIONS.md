# Decisions

- 2026-10-10: One name everywhere: `minicourse-as-a-lead-magnet` (repo, Railway, GCP, OAuth app, package).
- 2026-10-10: Zero npm dependencies on the server. Node built-in http and fetch only.
- 2026-10-10: The browser builds one normalized course payload (`Outline.pushCourse`), and every push route accepts the same payload.
- 2026-10-10: GHL import uses header `Version: 2021-07-28`. Verified live. The docs page is labeled v3 but names no header value.
- 2026-10-10: GHL posts are sent with `contentType: "video"` and `visibility: "draft"`, lesson text as HTML in `description`.
- 2026-10-10: Whop lessons are `lesson_type: "text"` with markdown content, course `visibility: "hidden"`.
- 2026-10-10: MCG has no API key. Only an MCP server behind OAuth, with open client registration. The OAuth client is registered per visitor session and kept in the browser tab, nothing on the server.
- 2026-10-10: YouTube sign-in uses the Google token flow in the browser, scope `youtube.force-ssl` only. No Google secret or refresh token exists anywhere.
- 2026-10-10: The video brief is named Video Course Content Brief, documented in `schema/video-course-content-brief.md`.
- 2026-10-10: Answers and outline are kept in sessionStorage (this tab only). The AI key is kept in sessionStorage only.
- 2026-10-10: MCG mapping: one MCG Course, one draft Module, our modules become its Sections, lessons are `info` lessons with a cards block (Teach, Do, Review). No landingPage and no image blocks are sent, so no AI credits are used.
- 2026-10-10: Whop puts a placeholder chapter and lesson into every new course. They are filled with the first module and lesson (PATCH), not left empty.
- 2026-10-10: Whop course link is `whop.com/experiences/{exp_id}/`, which Whop redirects to the company route.
- 2026-10-10: Zoltan asked for one-click generation paid by his own Gemini key. The key lives only in the Railway variable `GEMINI_API_KEY` and is used by `/api/ai/generate`. This departs from the original brief ("no keys on my server"). The route builds the prompt itself from the answers, so it can only write course outlines. Limits: 4 per visitor address per 10 minutes, `AI_DAILY_LIMIT` (default 200) per day.
- 2026-10-10: Gemini model order: `GEMINI_MODEL` (default `gemini-flash-latest`), then `GEMINI_FALLBACK_MODELS` (default `gemini-3-flash-preview,gemini-flash-lite-latest`). `gemini-2.5-flash` is retired for new users.
- 2026-10-10: Own AI key mode shows Gemini only. Claude, ChatGPT and Grok are listed as "coming soon".
- 2026-10-10: Zoltan dropped the separate brand-design route. The brand design replaced the first look on the main page. Design source: `YogiZoli/design-system` `tokens.css` (v3 "Shine"), copied verbatim to `public/tokens.css`. App styles are in `public/app.css` and read role tokens only. Open Sans is embedded in the PDF from `public/fonts`.
- 2026-10-10: Button roles: `.btn.big` is the one primary (fuchsia) action of a screen, plain `.btn` is the ink secondary, `.btn.ghost` is quiet.
- 2026-10-10: Static files are served with `Cache-Control: no-cache`, so a reload always shows the current build.
- 2026-10-10: Reliability pass. Rules that now hold everywhere: no request can hang (every call has a time limit), no raw error reaches the visitor, every long step shows a live status with seconds and says whether the tab must stay open, every error carries a ref that matches one server log line, and the visitor has an activity log to copy.
- 2026-10-10: A 429 from a platform is retried up to 2 times (the platform refused without doing anything). A timeout on a create call is never retried, because the platform may have done it: the visitor is told to check there first.
- 2026-10-10: The hosted AI answer is validated on the server. An incomplete outline counts as a failed model and the next model is tried. A model that worked is preferred for 15 minutes.
- 2026-10-10: `Outline.normalize` skips anything that is not a real module or lesson and drops modules without lessons, so a sloppy AI answer cannot break a push.
- 2026-10-10: Clearing the outline takes a second click. The browser warns before the tab is closed while work is running.
